# v2.0 — Power BI Interactive Dashboard

## What was added over v1.0

- Rebuilt the Olist e-commerce analysis as an interactive Power BI dashboard.
- Added a proper data model connecting Orders, OrderItems, Products, Customers, CategoryTranslation, and Date.
- Added interactive filters for order date, state, product category, and customer city.
- Added KPI cards for total orders, item sales, customers, and average delivery variance.
- Added revenue analysis by product category.
- Added monthly order-volume trend analysis.
- Added average delivery variance analysis by state.
- Added top-city sales and order-volume analysis.
- Added an Insights & Analytics page with key findings and business implications.
- Added a Data Dictionary page for easier interpretation of the model.
- Added drill-down and cross-filtering interactions across visuals.

## Key insight

Health & Beauty is the leading product category by item sales, while delivery performance varies considerably across Brazilian states. Order volume also shows substantial growth through the main analysis period.
